# Lista de compras

[**Abrir la aplicación**](https://jhonjairochaverra2-glitch.github.io/lista-de-compras/)

Una aplicación web ligera para organizar una compra desde el celular.

## Funciones

- Añadir productos y cantidades.
- Marcar lo que ya compraste.
- Guardar la lista en el navegador de ese dispositivo.
- Abrir la app sin conexión después de la primera visita.
- Instalarla desde el navegador en la pantalla de inicio del celular.

## Publicación

Este proyecto usa HTML, CSS y JavaScript sin dependencias externas. Puede publicarse gratis con GitHub Pages desde la rama `main` y la carpeta raíz (`/`).

## Privacidad

Los productos se guardan en `localStorage` del navegador. La app no envía la lista a un servidor ni usa APIs.
